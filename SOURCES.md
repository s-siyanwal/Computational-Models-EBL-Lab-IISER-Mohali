The models are built to reproduce and test results published by the authors below. All credit for the
experiments, data and original theory belongs to them.

**Rule we followed.** A third-party file is redistributed here only if its own licence allows it (Creative
Commons). Each one is listed with its licence and canonical source. Everything else is cited with a link, and
you must get it from the publisher or the authors.

## 4. Inputs needed to run everything

- **Project 2 recomputation and the hypothesis tests** read the BMC 2022 supplementary data in `experimental_papers_manas/`, which is included.
- **The Chinmay extension** embeds every number it uses from the thesis in code (`manas_sa/extensions/choice.py`, `config/*.yaml`), with provenance. It does not need the thesis PDF to run.
- **The extension brief** (`RD_simulator_extensions_chinmay.docx`, `acceptance_tests_extensions.csv`) is referred to in docstrings as `mate_choice_chinmay/`. It is not in this repository.
